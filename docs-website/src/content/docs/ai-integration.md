Generating code is easy; generating production-tested code is hard. Code needs to run in production to mature, and that is what our plugins and guides are for.

Even if you are not planning to use our plugins, their documentation can give your AI assistant better context about what is possible with Vendure plugins.

## Use the documentation

Find a relevant plugin with the search field or the [plugin overview](/#plugins), then share its documentation URL with your assistant. Each plugin page links to its npm package and changelog so you can check installation instructions and release history.

For example:

```text
I want to add store credit to my Vendure store. Read
https://plugins.pinelab.studio/plugin/vendure-plugin-store-credit/
and explain how to install and configure the plugin for my Vendure version.
```

You can also share the [Vendure guides](/guides/) for deployment, troubleshooting, and SEO advice. Always review generated changes and test them against your own Vendure configuration before deploying.
